Project 4: UW–Madison Intramural Sports Website

This project focused on designing and developing an interactive website for UW–Madison intramural sports. The goal was to create a more intuitive experience where students could explore sports opportunities, create teams, join teams, manage memberships, and view schedules.

Key Highlights:

  • Project Focus: Designed and developed a multi-page intramural sports website for UW–Madison students.
  • Front-End Development: Built responsive webpages using HTML, CSS, JavaScript, and Bootstrap.
  • Interactive Features: Developed features that allow users to create teams, join and leave teams, view team memberships, and access sport schedules.
  • Data Management: Used JavaScript and localStorage to store and update team and membership information dynamically.
  • Admin Functionality: Implemented administrative functionality for managing registered teams.
  • Collaboration: Worked as part of a team to integrate multiple webpages, debug functionality, and develop a complete interactive website.
  • Tools & Technologies: HTML, CSS, JavaScript, Bootstrap, GitHub, and browser localStorage.
